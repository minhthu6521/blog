> This to me is perhaps one of the most confusing parts of Finnish grammar. I do get the notion of consonant gradation to make the sound more pleasant, but the rules vary a lot in different situations.
> Anyway, this is one of the must-know rules as well.


The k-p-t rule can be summarized in one table:

| vahva | heikko | esimerkki               |
| ----- | ------ | ----------------------- |
| kk    | k      | Afrikka -> Afrikasta    |
| pp    | p      | Eurooppa-> Euroopassa   |
| tt    | t      | konsertti -> konsertin  |
|       |        |                         |
| k     | -      | Turku -> Turussa        |
| p     | v      | kylpy → kylvyssä        |
| t     | d      | katu -> kadulla         |
|       |        |                         |
| nk    | ng     | Helsinki -> Helsingissä |
| nt    | nn     | Irlanti → Irlannin      |
| mp    | mm     | kampa -> kammalla       |
| lt    | ll     | ilta → illalla          |
| rt    | rr     | parta -> parran         |
|       |        |                         |
| lke   | lje    | polkea → poljen         |
| rke   | rje    | särkeä → särjen         |
| hke   | hje    |                         |

However, usage of this (from weak -> strong) and vice versa depends on different situations. There are also 2 exceptions to the k-p-t rule:
- Ei k-p-t-vaihtelu: sk, st, tk 
- Ei k-p-t-vaihtelu: 2 vokaalia lopussa ( va**p**aa → va**p**aassa, kei**tt**iö → kei**tt**iössä )

It seems really easy at first, but when encountering it in practice, I started to forget all the rules and patterns, especially when there is a need for quick reaction i.e chatting or listening. So my advice would be to learn it by heart i.e make it so that everything can come without you making the effort of remembering the rules.

# Finnish verb types
Finnish verbs are categorized into six basic types

| Type | Infinitive ending | Stem rule | k-p-t direction |
|---|---|---|---|
| 1 | two vowels, last is -a/-ä (-aa, -ea, -eä, -ia, -iä, -oa, -ua, -yä, -ää, -öä) | drop the final -a/-ä | strong → weak |
| 2 | -da / -dä | drop -da/-dä | strong → weak |
| 3 | -lla/-llä, -nna/-nnä, -rra/-rrä, -sta/-stä | drop the final consonant + vowel, add -e- | weak → strong |
| 4 | -ata/-ätä, -ota/-ötä, -uta/-ytä | drop -t, keep the -a/-ä | weak → strong |
| 5 | -ita/-itä | drop -ta/-tä, add -tse- | — |
| 6 | -eta/-etä | drop -ta/-tä, add -ne- | weak → strong |

## Type 1: Verbs ending in 2 vowels with the last vowel being -a or -ä
This includes verbs that ends in -aa, -ea, -eä, -ia, -iä, -oa, -ua, -yä, -ää, -öä. The *Vartalo* (stem) of these verbs is usually formed by removing the last *-a* or *-ä* from the infinitive form.
Some of the most common verbs that are used in every day life comes from this type, such as *katsoa* (to watch), *laulaa* (to sing), *ajaa* (to drive), *nukkua* (to sleep), *puhua* (to speak), etc.

Example:

| | |
|---|---|
| Infinitiivi | tanssi**a** |
| Vartalo | tanssi- |
| minä | tanssin |
| sinä | tanssit |
| hän | tanss**ii** |
| me | tanssimme |
| te | tanssitte |
| he | tanssivat |

**k-p-t rules**: Verb 1 follows k-p-t rules from the direction of strong -> weak. For example:
- Aloitan työn nyt. _Aloitta_ -> _Aloita_

## Type 2: Verbs ending in -da or -dä
This includes verbs that ends in -da or -dä. The *Vartalo* (stem) of these verbs is usually formed by removing the last *-da* or *-dä* from the infinitive form.
2 of the most common verbs in this type are *syödä* (to eat) and *juoda* (to drink).

Example:

| | |
|---|---|
| Infinitiivi | syö**dä** |
| Vartalo | syö- |
| minä | syön |
| sinä | syöt |
| hän | syö |
| me | syömme |
| te | syötte |
| he | syövät |

**k-p-t rules**: Verb 2 follows k-p-t rules from the direction of strong -> weak. There are only 2 words: nähdä and tehdä. For example:
- Tekee töitä koko päivän. _Tehdä_ -> _Tee_ -> _Tekee_

## Type 3: Verbs ending in -lla/-llä, -nna/-nnä, -rra/-rrä, -sta/-stä
This is 2 consonants + 1 vowel type of verbs. The *Vartalo* (stem) of these verbs is usually formed by removing the last consonant + vowel and adding -e- to the stem.

Example:

| | |
|---|---|
| Infinitiivi | tulla |
| Vartalo | tul**e**- |
| minä | tulen |
| sinä | tulet |
| hän | tulee |
| me | tulemme |
| te | tulette |
| he | tulevat |

**k-p-t rules**: Verb 3 follows k-p-t rules from the direction of weak -> strong. For example:
- Ajattelen, että voisin joskus mennä pianotunnille. _Ajatella_ -> _Ajattele_

## Type 4: Verbs ending in -ata/-ätä, -ota/-ötä, -uta/-ytä
The *Vartalo* (stem) of these verbs is usually formed by removing the last "t" and keep the last 'a or 'ä'.

Example:

| | |
|---|---|
| Infinitiivi | halut**a** |
| Vartalo | halua- |
| minä | haluan |
| sinä | haluat |
| hän | haluaa |
| me | haluamme |
| te | haluatte |
| he | haluavat |

**k-p-t rules**: Verb 4 also follows k-p-t rules from the direction of weak -> strong like verb 3. For example:
- Lupaan sinulle, että tulen huomenna. _Luvata_ -> _Lupaa_

## Type 5: Verbs ending in -ita/-itä
I feel like this type is the type for abstract verbs, since so many of those verbs are from this type. It is less common compared to other word types, but it has some really nice words.
The *Vartalo* (stem) of these verbs is usually formed by removing the last 'ta' or 'tä' and adding -tse- to the stem.

Example:

| | |
|---|---|
| Infinitiivi | häiri**tä** |
| Vartalo | häiri**tse**- |
| minä | häiritsen |
| sinä | häiritset |
| hän | häiritsee |
| me | häiritsemme |
| te | häiritsette |
| he | häiritsevät |

## Type 6: Verbs ending in -eta/-etä
This type of verb implies changing one state to another. Most of these verbs that imply a change will have an adjective as their base.
The *Vartalo* (stem) of these verbs is usually formed by removing the last 'ta' or 'tä' and adding -ne- to the stem.

Example:

| | |
|---|---|
| Infinitiivi | vanhe**ta** |
| Vartalo | vanhe**ne**- |
| minä | vanhenen |
| sinä | vanhenet |
| hän | vanhenee |
| me | vanhenemme |
| te | vanhenette |
| he | vanhenevat |

**k-p-t rules**: Verb 6 follows k-p-t rules from the direction of weak -> strong. For example:
- Kalpenen aina vähän, kun näen verta. _Kalveta_ -> _Kalpene_
